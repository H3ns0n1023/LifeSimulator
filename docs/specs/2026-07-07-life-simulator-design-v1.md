人生模拟器游戏需求文档
一、游戏概述
1.1 游戏定位
•	类型：文字模拟养成游戏
•	平台：网页端（PC/移动端浏览器）
•	核心体验：从1岁到去世的人生模拟，关键节点自主决策，主打'出乎意料'的戏剧性体验
•	风格：职场为主线，兼顾天马行空的脑洞事件
•	目标用户：18-35岁职场人群、喜欢文字冒险/模拟养成的玩家
1.2 核心卖点
•	高度随机性：相同选择可能触发完全不同的结果
•	职场黑色幽默：讽刺现实、意外反转的剧情设计
•	脑洞事件：穿插荒诞但不失逻辑的奇遇（如：加班猝死穿越回高考、被外星人绑架后成为星际HR）
•	多结局系统：每个选择都会影响人生走向，累计产生数百种结局
二、核心玩法
2.1 基础循环
年龄推进 → 随机事件触发 → 玩家选择/自动判定 → 属性变化 → 下一年龄
2.2 人生阶段划分
阶段	年龄	核心事件类型
幼儿期	1-6岁	天赋觉醒、家庭环境
学龄期	7-18岁	学业、兴趣培养、初恋
大学期	19-22岁	专业选择、社团、实习
职场期	23-60岁	工作、升职、创业、婚恋、家庭
退休期	61-去世	遗产、回忆、彩蛋结局
2.3 核心属性系统
基础属性（影响事件触发概率）：
•	智力：影响学业、职场表现
•	魅力：影响人际关系、恋爱
•	体质：影响健康、寿命、加班承受力
•	运气：影响随机事件质量
•	财富：影响消费、投资机会
•	快乐：影响心理健康，过低会触发抑郁/摆烂事件
职场专属属性：
•	技能点：编程、沟通、管理、PPT、摸鱼等
•	人脉：同事、领导、客户、猎头关系网
•	声望：行业口碑，影响跳槽和创业
三、关键节点设计
3.1 节点类型
每个阶段设置2-5个关键选择节点，玩家必须做出决策：
学业节点：高考志愿选择、大学是否转专业、考研/留学/直接工作
职场节点：第一份工作选择、是否接受996、领导画饼接不接、跳槽机会、创业还是打工
人生节点：初恋对象选择、结婚/不婚/丁克、买房/租房/躺平、中年危机处理
3.2 选择机制
•	显性选择：2-4个选项，结果相对可预测
•	隐藏选择：通过日常小事件积累，影响隐藏结局
•	随机选择：部分事件强制随机（如：突发疾病、裁员潮）
四、'出乎意料'系统设计
4.1 反转机制
设计原则：看似合理的选择，可能触发荒诞结果
选择	常规预期	反转结果
努力加班	升职加薪	猝死穿越回高考，带着记忆重活一遍
摸鱼划水	被开除	摸鱼写的小说爆火，成为全职作家
接受画饼	被骗	饼成真了，公司上市，财务自由
拒绝996	被裁员	被竞争对手挖走，工资翻倍
投资加密货币	血本无归	买的山寨币成为meme币，暴涨1000倍
4.2 脑洞事件库
职场荒诞类：
•	老板突然信佛，公司改为素食主义，全员吃素
•	公司引入AI管理，AI比人类领导更懂PUA
•	团建漂流到荒岛，意外发现石油
•	年会抽奖中了一头羊，成为网红羊主人
天马行空类：
•	加班猝死穿越，带着职场经验重活高考
•	被外星人绑架，因PPT做得好成为星际HR
•	梦到已故亲人，获得神秘代码买彩票中奖
•	被误认为商业大佬，将错就错真的创业成功
4.3 蝴蝶效应系统
早期的小选择会在10-20年后产生连锁反应：
•	小学时救了一只猫 → 20年后猫的后代成为网红，你成为宠物博主
•	大学时写的代码bug → 10年后成为网络安全漏洞，你被黑客运维
•	第一份工作认识的同事 → 15年后成为你的面试官
五、结局系统
5.1 结局分类
常规结局（约50种）：富豪、平凡、失败、幸福、孤独等
隐藏结局（约30种）：需要特定属性组合或隐藏选择触发
脑洞结局（约20种）：触发天马行空事件链
5.2 结局评分
•	财富分：最终资产
•	快乐分：心理健康指数
•	成就分：职业高度、社会贡献
•	人脉分：关系网质量
•	综合评级：S/A/B/C/D
六、数值与经济系统
6.1 年龄推进
•	每回合=1年（可设置快进/慢放）
•	每回合自动触发1-3个随机事件
•	关键节点强制玩家选择
6.2 事件触发逻辑
事件触发 = 基础概率 × 属性修正 × 前置条件
6.3 经济系统
•	收入：工资、投资收益、副业
•	支出：房租/房贷、生活消费、医疗
•	负债：房贷、车贷、网贷（影响快乐值）
•	投资：股票、基金、房产、加密货币（高风险高回报）
七、特色系统
7.1 职场黑话系统
随机触发领导PUA话术，玩家需要选择应对方式：
•	忍气吞声 → 快乐-10，人脉+5
•	据理力争 → 快乐+5，人脉-10
•	反向PUA → 需要高智力，成功则人脉+10
7.2 摸鱼系统
工作时间内可触发摸鱼事件，摸鱼可能：
•	被抓到 → 被批评，声望-5
•	摸鱼写小说爆火 → 转职作家
•	摸鱼学技能 → 技能点+10
7.3 中年危机系统
40-50岁强制触发，根据前期积累可能：
•	事业巅峰，危机解除
•	失业离婚，人生低谷
•	顿悟出家，触发隐藏结局
7.4 二周目系统
•	通关后可开启二周目
•	保留部分属性（如智力、技能点）
•	解锁隐藏剧情和彩蛋结局
•	可继承前世记忆（某些事件有额外选项）
八、UI与交互设计
8.1 美术风格
•	主风格：像素风/简笔画（低成本，适合文字游戏）
•	配色：职场冷色调（灰、蓝）+ 脑洞事件暖色调（红、黄）
•	动画：关键节点有简单动画（如：升职时撒金币、猝死时屏幕碎裂）
九、商业化设计
9.1 免费模式
•	基础游戏免费
•	广告复活（猝死后看广告重来）
•	广告解锁隐藏事件
9.2 付费内容
•	去广告（一次性购买）
•	皮肤包（角色形象、界面主题）
•	DLC剧情包（如：创业篇、明星篇）
•	二周目继承券（保留更多前世属性）
9.3 社交功能
•	结局分享（生成人生总结海报）
•	排行榜（财富榜、快乐榜、寿命榜）
•	好友对比（看朋友的人生轨迹）
十、开发计划
10.1 核心版本（MVP）
•	实现1-60岁完整流程
•	50个基础事件
•	10个关键节点
•	5种结局
•	开发周期：2-3个月
10.2 完整版本
•	1-100岁完整流程
•	200+事件（含脑洞事件）
•	30+关键节点
•	100+结局
•	二周目系统
•	开发周期：6-8个月
10.3 技术选型
•	前端：HTML5 + JavaScript/TypeScript（Vue/React框架）
•	后端：Node.js + Express（排行榜、存档、用户系统）
•	数据库：MySQL/PostgreSQL（用户数据、事件库）
•	部署：静态资源CDN + 云服务器
•	事件编辑器：自研Web工具（策划可配置事件）
